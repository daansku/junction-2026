## Short Pitch (Portal Summary — ~60 words)

We built a procedurally seeded 64×64 pixel reinforcement-learning curriculum (`engine 0.2.0`) where agents receive zero prose rules, object colors shuffle per game (`skin_shuffle`), and seven composable mechanics are introduced one rule per level before multi-rule exam levels. Action-efficiency scoring against BFS shortest paths exposes inductive rule-discovery and reset-planning gaps while provably scoring `noop` and `stop_early` at `0.000`.

## How It Maps to the AfterQuery Judging Rubric (100 Points)

### 1. The Gap (30 pts)
- **BFS Optimal Reference (`optimal` baseline):** `1.000` action-efficiency score (`15/15` levels solved across `3` dev fixture games, `0` resets, `0.0%` no-effect rate).
- **Evaluated Agent Fixture (`mock-model`, `fixture-run-0001`, 6-level game `gridworld-s2-d2-l6-f978fc99`):** `0.252` (`0.252381`) overall action-efficiency score (`2/6` levels solved: `5/7 = 0.714` on Level 1, `16/20 = 0.800` on Level 2, `0.000` on Levels 3–6), `30` total actions, `1` late reset (`@step 11`), `1` wall-bump no-effect action (`@step 10`, `3.33%` rate).
- **Random Walk Reference (`random` baseline):** `0.008` (`0.007752`, `1/15` levels solved across dev fixture games, `32.17%` no-effect rate).
- **Live Sweeps:** `arena/` supports full multi-provider sweeps (Anthropic, Gemini, NVIDIA, Featherless, Verda/Modal) and human playtesting under identical pixel-only observation constraints (`h1` harness + MCP server `python -m server mcp`).

### 2. Meaningful Difficulty (30 pts)
- **Full Observability in Pixels:** Every mechanic renders distinct sprites (`keys_doors`, `plates_gates`, `teleporters`, `hazards`, `push_blocks`, `one_way`, `ice`) alongside a clear top HUD (`rows 0–1`: move-budget bar, `rows 3–4`: level pips & held-key / health indicators).
- **Mathematical Fairness Guarantees:** Every level generated by `engine` passes BFS solvability (`optimal_moves` & `optimal_path`), rule-necessity verification (removing any active rule alters optimal path or breaks solvability), `random`-walk rejection (`< 2%` win probability), and bounded slack (`move_budget = ceil(optimal_moves × slack)`).
- **Explainable Mistake Traces:** `steps.jsonl` records per-step `reasoning`, `hypothesis`, and `belief`, feeding `analysis` rule-discovery diagnostics (`actions_to_first_use`, `wasted_actions`, `hypothesis_match_rate`, `belief_accuracy`) and deep links into `/replay/<run_id>?step=<step>`.

### 3. Reward Integrity (25 pts)
- **Scoring Equation (`analysis/METRICS.md`):**
  `level_score(L) = min(1.0, optimal_moves(L) / actions_used(L))` if solved, else `0.0`; averaged over all `levels_total` levels (`1..levels_total`).
- **Verified Zero-Exploit Baselines (`data/fixtures/derived/leaderboard.json`):**
  - `noop` (`0` actions): `0.000`
  - `stop_early` (`5` median actions, aborted before Level 1 solve): `0.000`
  - Reset farming penalty: `actions_used(L)` includes all actions before a `RESET` plus the `RESET` step itself, strictly reducing `level_score(L)` whenever an agent resets (`test_reward_integrity_and_reset_penalty`).
  - Anti-cheat isolation: `Truth` (`optimal_moves`, `events`, `active_rules`, `new_rule`) never leaves the server/evaluator in agent prompts or MCP responses.

### 4. Craft & Reproducibility (15 pts)
- **One-Command Setup & Evaluation:** See root `README.md` (`make setup && make test`, `make smoke`, `python -m server mcp`).
- **Automated Schema & Claim Verification:** `contracts/derived.schema.json` + `python -m analysis check-claims` verifies schema validity (`oneOf`) and numerical invariants across `leaderboard.json`, `rules.json`, and `insights.json` (plus unit tests in `analysis/tests/test_analysis.py`).
- **Harbor + OpenCode MCP Integration:** `python -m server mcp [--api URL]` exposes `list_games`, `start_game`, `act`, and `reset` returning pixel PNG + text frames so external judges can rerun `reference`, `3 × agent`, `noop`, and `stop_early` seamlessly.
